# Unity WebGL exports

Create a folder per project, for example `magnet-madness/`. Copy the complete Unity Web/WebGL export into that folder, including `index.html`, `Build/`, `TemplateData/`, and any other generated output.

Set that project's `webglUrl` in `assets/data/projects.js` to `webgl/magnet-madness/index.html` only after copying your actual build. The folder currently contains no compiled game. Follow `docs/MEDIA-GUIDE.md` for Unity compression settings, hosting limits, and external hosting options.
