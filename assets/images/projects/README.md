# Project thumbnails

Place project screenshots here. Suggested names:

- `magnet-madness.webp`
- `engineering-marvels.webp`
- `flappy-bird.webp`
- `slot-machine.webp`
- `realtime-chat.webp`
- `weather-app.webp`

Use a 16:9 landscape image, ideally 1200 × 675 pixels. Set the matching project's `thumbnail` in `assets/data/projects.js` to `assets/images/projects/FILENAME.webp`. Leave it empty to retain the illustrated cover. See `docs/MEDIA-GUIDE.md` for examples.
